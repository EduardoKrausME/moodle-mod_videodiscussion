# Video Discussion (mod_videodiscussion)

Video Discussion is a Moodle activity that connects threaded discussions directly to moments in a video.

Students can create a discussion at the current playback position, reply to classmates, jump from a discussion back to
its timestamp, and see discussion markers on the video timeline. Teachers can create predefined discussion prompts, mark
prompts as mandatory, require students to post before seeing peers, highlight important responses, use Moodle groups,
and grade participation.

The activity also tracks video progress by watched segments and stores the last playback position so learners can resume
later.

## Main features

- HTML5 video from a direct URL or uploaded file.
- YouTube and Vimeo playback support.
- Resume playback from the saved position.
- Watched-segment tracking and watched percentage.
- Student-created timestamped discussions.
- Teacher-created timestamped discussion prompts.
- Mandatory prompts.
- "Post before viewing peers" mode.
- Separate groups and visible groups.
- Highlighted responses.
- Participation grading integrated with the Moodle gradebook.
- Timeline markers for discussions.
- Participation report with comments, replies, mandatory prompts answered, watched percentage and grade.
- Backup and restore support.
- Privacy API support.

## Installation

Copy the plugin directory to `mod/videodiscussion` and visit Site administration > Notifications.
